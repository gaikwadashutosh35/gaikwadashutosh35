## About Me

I am a **Full Stack Software Engineer** at **Fujitsu**, where I have spent nearly five years building and supporting enterprise applications, growing from Technical Service Trainee to **Assistant Technical Services Engineer**. My work spans the full delivery lifecycle — designing REST and GraphQL APIs, modelling relational data, and shipping responsive interfaces in **React** and **Angular** on top of **Java / Spring Boot** services.

I approach software with a **product engineering mindset**: understand the user problem first, choose the simplest architecture that scales, and keep the codebase maintainable for the next engineer. Alongside core engineering, I work with **AI and LLM technologies** — from an early machine learning internship to integrating AI assistants into full stack products and exploring agentic tooling such as the Model Context Protocol.

- **Software Engineering** — Java, Spring Boot, Spring MVC, microservices, REST & GraphQL API design
- **Full Stack Development** — React, Angular, Tailwind CSS, SQL Server, MySQL, MongoDB
- **AI / ML** — LLM-powered features, AI chatbots, ML fundamentals, MCP-based tooling
- **Enterprise Platforms** — Microsoft Azure, SAP BTP, ABAP RESTful applications, PowerShell automation
- **Leadership** — mentoring junior developers and improving team delivery
